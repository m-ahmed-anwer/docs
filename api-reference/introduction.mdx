## 1. Get credentials

After Fleeticc enables Partner API on your account, the **owner** generates keys in the website dashboard (**Partner API** in the account menu).

| You create | Used for |
|------------|----------|
| **API key** | Identifies your integration (`X-Api-Key`) |
| **Secret** | Signs every request (keep this private) |

The secret is shown **only once** when you generate or rotate a key. Store it on your server only — never in a mobile app or public website. You can rotate keys anytime from the same page.

## 2. Call the API

Base URL:

```
https://api.fleeticc.com
```

Every request needs three headers (see [Authentication](/api-reference/endpoint/authentication)):

- `X-Api-Key`
- `X-Timestamp`
- `X-Signature`

## 3. Typical flow

1. **List vehicles** — save Fleeticc `vehicleId` / `imei` in your system  
2. **Live location** — show vehicles on a map  
3. **History** — review past trips, or get the location at a specific time  

## Available endpoints

| What you need | Method | Path |
|---------------|--------|------|
| Vehicle list | `GET` | `/api/partner/v1/vehicles` |
| Live positions | `GET` | `/api/partner/v1/track` |
| Live updates (stream) | `GET` | `/api/partner/v1/track/stream` |
| History | `GET` | `/api/partner/v1/history` |

That’s the full Partner API for now. Webhooks are not available yet.

## How responses look

**Success**

```json
{
  "code": "200",
  "message": "…",
  "data": { }
}
```

**Error**

```json
{
  "code": "401",
  "message": "…",
  "data": null,
  "error": "PARTNER_AUTH_INVALID"
}
```

Use the HTTP status and the `error` field when handling failures. Full list: [Error codes](/api-reference/endpoint/error-codes).
