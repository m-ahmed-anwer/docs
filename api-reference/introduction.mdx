## Overview

Use the Partner API when your own backend (for example a city garbage collection system) needs Fleeticc GPS data without using the Fleeticc mobile or web apps.

**Available today**

| Endpoint | Method | Path |
|----------|--------|------|
| List vehicles | `GET` | `/api/partner/v1/vehicles` |
| Live snapshot | `GET` | `/api/partner/v1/track` |
| Live SSE stream | `GET` | `/api/partner/v1/track/stream` |
| History / QR nearest | `GET` | `/api/partner/v1/history` |

Webhooks and other fleet APIs are **not** part of this Partner surface yet.

## Base URL

```
https://api.fleeticc.com
```

Example full URL:

```
https://api.fleeticc.com/api/partner/v1/vehicles
```

## Enablement

1. Fleeticc enables **External Partner API** on your fleet owner account.
2. Fleeticc issues an `apiKeyId` + `apiSecret` (secret shown once).
3. Your backend signs every request with HMAC-SHA256 (see [Authentication](/api-reference/endpoint/authentication)).

Without the enablement flag, even a valid key is rejected (`PARTNER_EXTERNAL_API_DISABLED`).

## Response shape

Success:

```json
{
  "code": "200",
  "message": "Partner vehicles listed successfully.",
  "data": { }
}
```

Error:

```json
{
  "code": "401",
  "message": "Invalid partner signature.",
  "data": null,
  "error": "PARTNER_AUTH_INVALID"
}
```

- HTTP status matches the numeric `code` string.
- Machine-readable reason is in `error` (string codes such as `PARTNER_AUTH_INVALID`).

## Security summary

- Separate URL namespace: `/api/partner/v1` (not the mobile/web JWT routes).
- HMAC-SHA256 with clock skew ±5 minutes.
- Keys bound to one owner; only that owner's vehicles are returned.
- Rate limits keyed by `X-Api-Key` (see [Rate limits](/api-reference/endpoint/rate-limits)).

## Recommended integration flow

1. Call **List vehicles** once and map Fleeticc `vehicleId` / `imei` into your database.
2. **Live map**: prefer SSE `track/stream`; fallback poll `track` every few seconds.
3. **QR collection**: call history with `at=<scanUnix>`; if `point` is null, retry later (delayed GPS).
4. **Trip playback**: history with `from` + `to`.
