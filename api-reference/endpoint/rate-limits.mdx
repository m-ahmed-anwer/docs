---
title: "Rate limits"
description: "How many Partner API requests you can send"
---

Limits apply **per API key**.

Fleeticc also enforces a **per IP** ceiling on Partner routes so forged or rotated keys cannot bypass limits.

| Endpoint | Per API key | Per IP (ceiling) |
|----------|-------------|------------------|
| List vehicles | 60 / minute | 90 / minute |
| Live snapshot | 120 / minute | 150 / minute |
| Live stream | 30 new connections / minute | 40 / minute |
| History | 60 / minute | 90 / minute |

If you go over either limit, you get **HTTP 429**.

```json
{
  "code": "429",
  "message": "Too many attempts; try again later.",
  "data": null,
  "error": "TOO_MANY_REQUESTS"
}
```

Wait a moment, then retry. For continuous live maps, prefer the **stream** instead of polling very fast.
