## Snapshot

```
GET https://api.fleeticc.com/api/partner/v1/track
```

### Query

| Param | Required | Description |
|-------|----------|-------------|
| `imeis` | no | Comma-separated IMEIs (1–100) |
| `vehicleIds` | no | Comma-separated Fleeticc vehicle UUIDs |

Omit both to receive up to **100** vehicles for the owner.

Sign the full path **with** the query string, e.g. `/api/partner/v1/track?imeis=3596…`.

### Response `data`

```json
{
  "record": [
    {
      "vehicleId": "8f3c2a1b-…",
      "imei": "35963310……",
      "plateNumber": "ABC-1234",
      "vehicleName": "Truck 01",
      "latitude": 7.2916,
      "longitude": 80.6349,
      "speed": 32.5,
      "course": 180,
      "accstatus": 1,
      "gpstime": 1761200000,
      "servertime": 1761200001,
      "hearttime": 1761200001,
      "datastatus": 1,
      "lastSeen": 1761200001
    }
  ]
}
```

| Field | Description |
|-------|-------------|
| `latitude` / `longitude` | WGS84 |
| `speed` | km/h |
| `accstatus` | Ignition when the device reports it (`0` / `1`) |
| `gpstime` / `servertime` / `hearttime` | Unix seconds |
| `lastSeen` | Max of recent activity timestamps |
| `datastatus` | Connectivity / freshness status used by Fleeticc maps |

### Rate limit

**120 requests / minute** per `X-Api-Key`.

## SSE stream

```
GET https://api.fleeticc.com/api/partner/v1/track/stream?imeis=…
```

Same query rules as the snapshot. Keep the connection open (EventSource / SSE client). HMAC headers are still required on the initial HTTP request.

### Events

| `event` / `type` | Payload |
|------------------|---------|
| `track.snapshot` | `{ "record": [ …live points… ] }` |
| `track.update` | `{ "record": [ oneLivePoint ] }` |
| `track.heartbeat` | `{ "ts": <unixSec> }` |

### Recommendation

- Admin live map → **SSE**
- Occasional customer “where is my truck” → **snapshot** poll (3–10s) or on-demand GET

### Rate limit

**30 new stream connections / minute** per `X-Api-Key` (existing streams stay open).
