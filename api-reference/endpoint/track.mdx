---
title: "Live location"
description: "Get current vehicle positions, or stream live updates"
openapi: "GET /api/partner/v1/track"
---

Two options:

- **Snapshot** — one request, current positions  
- **Stream** — keep a connection open and receive updates as they happen  

## Snapshot

```
GET https://api.fleeticc.com/api/partner/v1/track
```

### Headers

<ParamField header="X-Api-Key" type="string" required>
  Your Partner API key
</ParamField>

<ParamField header="X-Timestamp" type="string" required>
  Unix seconds
</ParamField>

<ParamField header="X-Signature" type="string" required>
  HMAC signature — must cover the **exact** path including query string
</ParamField>

### Query

<ParamField query="imeis" type="string">
  Comma-separated IMEIs (optional). Example: `3596…,3597…`
</ParamField>

<ParamField query="vehicleIds" type="string">
  Comma-separated Fleeticc vehicle UUIDs (optional)
</ParamField>

Leave both empty to get up to **100** vehicles for your account.

### Request example

```bash
export PATH="/usr/bin:/bin:/usr/sbin:/sbin:/opt/homebrew/bin:$PATH"
KEY="$FLEETICC_API_KEY"
SECRET="$FLEETICC_API_SECRET"
REQ_PATH="/api/partner/v1/track?imeis=359633100000001"
TS=$(date +%s)
BODY_HASH=$(printf '' | openssl dgst -sha256 -hex | awk '{print $NF}')
SIG=$(printf 'GET\n%s\n%s\n%s' "$REQ_PATH" "$TS" "$BODY_HASH" | openssl dgst -sha256 -hmac "$SECRET" -hex | awk '{print $NF}')

curl -sS -X GET "https://api.fleeticc.com$REQ_PATH" \
  -H "X-Api-Key: $KEY" \
  -H "X-Timestamp: $TS" \
  -H "X-Signature: $SIG"
```

### Example response

```json
{
  "code": "200",
  "message": "Partner track positions retrieved successfully.",
  "data": {
    "record": [
      {
        "vehicleId": "8f3c2a1b-4d5e-6f70-8192-a3b4c5d6e7f8",
        "imei": "359633100000001",
        "plateNumber": "ABC-1234",
        "vehicleName": "Truck 01",
        "latitude": 7.2916,
        "longitude": 80.6349,
        "speed": 32.5,
        "course": 180,
        "accstatus": 1,
        "gpstime": 1761200000,
        "servertime": 1761200001,
        "lastSeen": 1761200001
      }
    ]
  }
}
```

| Field | Description |
|-------|-------------|
| `latitude`, `longitude` | Position |
| `speed` | km/h |
| `course` | Heading in degrees |
| `accstatus` | Ignition when available (`0` / `1`) |
| `gpstime`, `servertime`, `lastSeen` | Unix time in seconds |

### Limits

Up to **120** requests per minute per API key.

## Live stream (SSE)

```
GET https://api.fleeticc.com/api/partner/v1/track/stream
```

Same headers and filters as the snapshot. Use an SSE / EventSource client and keep the connection open.

| Update type | Meaning |
|-------------|---------|
| `track.snapshot` | Full list when you connect |
| `track.update` | One vehicle moved / updated |
| `track.heartbeat` | Connection is alive |

### When to use which

| Use case | Suggested approach |
|----------|--------------------|
| Live ops map | Stream |
| Occasional “where is this vehicle?” | Snapshot every few seconds |

### Limits

Up to **30** new stream connections per minute per API key.
