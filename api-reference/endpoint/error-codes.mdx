---
title: 'Error codes'
description: 'Partner API error codes on api.fleeticc.com'
---

Errors use HTTP status in `code`, a human `message`, and a machine `error` string.

```json
{
  "code": "401",
  "message": "Invalid partner signature.",
  "data": null,
  "error": "PARTNER_AUTH_INVALID"
}
```

## Partner auth & access

| `error` | HTTP | When |
|---------|------|------|
| `PARTNER_AUTH_REQUIRED` | 401 | Missing `X-Api-Key`, `X-Timestamp`, or `X-Signature` |
| `PARTNER_AUTH_TIMESTAMP_SKEW` | 401 | Timestamp outside ±5 minutes |
| `PARTNER_AUTH_INVALID` | 401 | Unknown key, revoked key, undecryptable secret, or bad signature |
| `PARTNER_EXTERNAL_API_DISABLED` | 403 | Owner does not have External Partner API enabled |
| `PARTNER_KEY_INACTIVE` | 403 | (Admin tooling) key marked inactive — callers usually see `PARTNER_AUTH_INVALID` |
| `PARTNER_KEY_NOT_FOUND` | 404 | Admin revoke/list against a missing key id |
| `PARTNER_QUERY_INVALID` | 400 | History called without `from`+`to` or `at` |
| `FORBIDDEN` | 403 | Owner account disabled |

## Vehicles / GPS

| `error` | HTTP | When |
|---------|------|------|
| `VEHICLE_NOT_FOUND` | 404 | `vehicleId` / `imei` not on this owner |
| `TRACK_IMEIS_INVALID` | 400 | IMEI list empty or greater than 100 |
| `PLAYBACK_QUERY_INVALID` | 400 | Invalid playback parameters |
| `PLAYBACK_TIME_RANGE_INVALID` | 400 | Range too large / invalid |
| `DEVICE_NOT_CONNECTED` | 404 | No Timescale last-position / device data for playback |
| `VEHICLE_SUBSCRIPTION_EXPIRED` | 403 | Vehicle subscription not active for history |

## Generic HTTP

| `error` | HTTP | When |
|---------|------|------|
| `BAD_REQUEST` | 400 | Validation failure |
| `UNAUTHORIZED` | 401 | Auth failure (generic) |
| `NOT_FOUND` | 404 | Resource missing |
| `TOO_MANY_REQUESTS` | 429 | Rate limit exceeded |
| `INTERNAL_SERVER_ERROR` | 500 | Unexpected server error |

## Success

Successful Partner responses use:

```json
{
  "code": "200",
  "message": "…",
  "data": { }
}
```
