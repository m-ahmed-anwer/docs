---
title: "List vehicles"
description: "Get the vehicles linked to your Partner API account"
---

Use this once (or occasionally) to map Fleeticc vehicles into your own database.

## Request

```
GET https://api.fleeticc.com/api/partner/v1/vehicles
```

No query parameters. Requires [authentication](/api-reference/endpoint/authentication).

## Response

```json
{
  "code": "200",
  "message": "Partner vehicles listed successfully.",
  "data": {
    "vehicles": [
      {
        "vehicleId": "8f3c2a1b-…",
        "imei": "35963310……",
        "plateNumber": "ABC-1234",
        "vehicleName": "Truck 01"
      }
    ]
  }
}
```

| Field | Description |
|-------|-------------|
| `vehicleId` | Fleeticc vehicle id (best value to store) |
| `imei` | GPS device id |
| `plateNumber` | Number plate |
| `vehicleName` | Display name |

You only see vehicles for the account tied to your API key.

## Limits

Up to **60** requests per minute.
