title: 'List vehicles'

---

## Request

```
GET https://api.fleeticc.com/api/partner/v1/vehicles
```

Requires [HMAC authentication](/api-reference/endpoint/authentication). No query parameters.

## Response `data`

```json
{
  "vehicles": [
    {
      "vehicleId": "8f3c2a1b-…",
      "imei": "35963310……",
      "plateNumber": "ABC-1234",
      "vehicleName": "Truck 01"
    }
  ]
}
```

| Field | Type | Description |
|-------|------|-------------|
| `vehicleId` | string (UUID) | Stable Fleeticc vehicle id — prefer this for your mapping |
| `imei` | string | GPS device IMEI |
| `plateNumber` | string | Plate |
| `vehicleName` | string | Display name |

Only vehicles belonging to the API key’s owner are returned.

## Rate limit

**60 requests / minute** per `X-Api-Key`.
