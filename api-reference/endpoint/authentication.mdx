Every Partner API request must include three headers. There is **no** login password or JWT for partners.

## Headers

| Header | Description |
|--------|-------------|
| `X-Api-Key` | Public key id (`pk_…`) issued by Fleeticc |
| `X-Timestamp` | Unix time in **seconds** (must be within ±5 minutes of server time) |
| `X-Signature` | Lowercase hex HMAC-SHA256 of the canonical string |

## Canonical string

```text
METHOD
PATH_WITH_QUERY
TIMESTAMP
BODY_SHA256_HEX
```

1. `METHOD` — uppercase (`GET`)
2. `PATH_WITH_QUERY` — path **including** `/api` and the query string  
   Example: `/api/partner/v1/track?imeis=3596…`
3. `TIMESTAMP` — same value as `X-Timestamp`
4. `BODY_SHA256_HEX` — SHA-256 hex of the **raw** HTTP body  
   For all current Partner endpoints (GET), the body is empty → hash of `""`

Then:

```text
X-Signature = hex( HMAC-SHA256( apiSecret, canonicalString ) )
```

## Node.js example

```javascript
const crypto = require('crypto');

function signPartnerRequest({ method, pathWithQuery, timestamp, body, secret }) {
  const bodyHash = crypto.createHash('sha256').update(body ?? '').digest('hex');
  const payload = [
    method.toUpperCase(),
    pathWithQuery,
    String(timestamp),
    bodyHash,
  ].join('\n');
  return crypto.createHmac('sha256', secret).update(payload).digest('hex');
}

const timestamp = Math.floor(Date.now() / 1000);
const pathWithQuery = '/api/partner/v1/vehicles';
const signature = signPartnerRequest({
  method: 'GET',
  pathWithQuery,
  timestamp,
  body: '',
  secret: process.env.FLEETICC_API_SECRET,
});

// GET https://api.fleeticc.com/api/partner/v1/vehicles
// Headers:
//   X-Api-Key: pk_...
//   X-Timestamp: <timestamp>
//   X-Signature: <signature>
```

## curl example

```bash
BASE="https://api.fleeticc.com"
PATH_Q="/api/partner/v1/vehicles"
TS=$(date +%s)
BODY_HASH=$(printf '' | openssl dgst -sha256 -hex | awk '{print $2}')
PAYLOAD=$(printf 'GET\n%s\n%s\n%s' "$PATH_Q" "$TS" "$BODY_HASH")
SIG=$(printf '%s' "$PAYLOAD" | openssl dgst -sha256 -hmac "$FLEETICC_API_SECRET" -hex | awk '{print $2}')

curl -sS "$BASE$PATH_Q" \
  -H "X-Api-Key: $FLEETICC_API_KEY" \
  -H "X-Timestamp: $TS" \
  -H "X-Signature: $SIG"
```

## Security notes

- Keep `apiSecret` only on your server. Never embed it in a customer mobile app.
- Sign the **exact** path + query the HTTP client sends (including parameter order).
- Skewed clocks fail with `PARTNER_AUTH_TIMESTAMP_SKEW`.
- Unknown, revoked, or badly signed keys return the same `401` + `PARTNER_AUTH_INVALID` (no key enumeration).
- If Partner API is disabled for the owner: `403` + `PARTNER_EXTERNAL_API_DISABLED`.
