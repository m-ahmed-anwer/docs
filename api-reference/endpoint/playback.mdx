---
title: "History"
description: "Past GPS points for a vehicle, or the nearest point at a given time"
---

```
GET https://api.fleeticc.com/api/partner/v1/history
```

Identify the vehicle with **either** `vehicleId` or `imei`.

## Trip history (time range)

| Query | Required | Description |
|-------|----------|-------------|
| `vehicleId` or `imei` | Yes | Which vehicle |
| `from` | Yes | Start time (Unix seconds) |
| `to` | Yes | End time (Unix seconds) |

Maximum range is about **7 days** per request.

### Example response

```json
{
  "code": "200",
  "message": "Partner GPS history retrieved successfully.",
  "data": {
    "mode": "range",
    "vehicleId": "8f3c2a1b-…",
    "imei": "35963310……",
    "from": 1761190000,
    "to": 1761200000,
    "record": [
      {
        "timestamp": 1761190100,
        "latitude": 7.29,
        "longitude": 80.63,
        "speed": 12,
        "heading": 90,
        "accstatus": 1
      }
    ]
  }
}
```

## Location at a specific time

Useful when you already have a timestamp (for example a stop or job event) and want the GPS point closest to that moment.

| Query | Required | Description |
|-------|----------|-------------|
| `vehicleId` or `imei` | Yes | Which vehicle |
| `at` | Yes | Time you care about (Unix seconds) |
| `windowSeconds` | No | Search ± this many seconds (default `300`) |

If GPS was offline at that moment, `point` may be `null`. Save `at` and try again later.

### Example response

```json
{
  "code": "200",
  "message": "Partner GPS history retrieved successfully.",
  "data": {
    "mode": "nearest",
    "at": 1761200000,
    "windowSeconds": 300,
    "point": {
      "timestamp": 1761199988,
      "latitude": 7.2911,
      "longitude": 80.635,
      "speed": 0,
      "heading": 10,
      "accstatus": 0
    }
  }
}
```

## Limits

Up to **60** requests per minute.
