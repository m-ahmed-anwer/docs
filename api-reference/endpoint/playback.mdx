```
GET https://api.fleeticc.com/api/partner/v1/history
```

Identify the vehicle with **either** `vehicleId` or `imei`.

## Headers

<ParamField header="X-Api-Key" type="string" required>
  Your Partner API key
</ParamField>

<ParamField header="X-Timestamp" type="string" required>
  Unix seconds
</ParamField>

<ParamField header="X-Signature" type="string" required>
  HMAC signature of the full path **including** the query string
</ParamField>

## Trip history (time range)

<ParamField query="vehicleId" type="string">
  Fleeticc vehicle UUID (or use `imei`)
</ParamField>

<ParamField query="imei" type="string">
  Device IMEI (or use `vehicleId`)
</ParamField>

<ParamField query="from" type="integer" required>
  Start time (Unix seconds)
</ParamField>

<ParamField query="to" type="integer" required>
  End time (Unix seconds)
</ParamField>

Maximum range is **7 days** per request.

### Request example

```bash
export PATH="/usr/bin:/bin:/usr/sbin:/sbin:/opt/homebrew/bin:$PATH"
KEY="$FLEETICC_API_KEY"
SECRET="$FLEETICC_API_SECRET"
IMEI="359633100000001"
FROM=$(($(date +%s) - 86400))
TO=$(date +%s)
REQ_PATH="/api/partner/v1/history?imei=${IMEI}&from=${FROM}&to=${TO}"
TS=$(date +%s)
BODY_HASH=$(printf '' | openssl dgst -sha256 -hex | awk '{print $NF}')
SIG=$(printf 'GET\n%s\n%s\n%s' "$REQ_PATH" "$TS" "$BODY_HASH" | openssl dgst -sha256 -hmac "$SECRET" -hex | awk '{print $NF}')

curl -sS -X GET "https://api.fleeticc.com$REQ_PATH" \
  -H "X-Api-Key: $KEY" \
  -H "X-Timestamp: $TS" \
  -H "X-Signature: $SIG"
```

## Location at a specific time

Useful when you already have a timestamp (for example a stop or job event) and want the GPS point closest to that moment.

<ParamField query="vehicleId" type="string">
  Fleeticc vehicle UUID (or use `imei`)
</ParamField>

<ParamField query="imei" type="string">
  Device IMEI (or use `vehicleId`)
</ParamField>

<ParamField query="at" type="integer" required>
  Time you care about (Unix seconds)
</ParamField>

<ParamField query="windowSeconds" type="integer">
  Search ± this many seconds (default `300`, max `3600`)
</ParamField>

If GPS was offline at that moment, `point` may be `null`. Save `at` and try again later.

### Example response

```json
{
  "code": "200",
  "message": "Partner GPS history retrieved successfully.",
  "data": {
    "mode": "nearest",
    "at": 1761200000,
    "windowSeconds": 300,
    "point": {
      "timestamp": 1761199988,
      "latitude": 7.2911,
      "longitude": 80.635,
      "speed": 0,
      "heading": 10,
      "accstatus": 0
    }
  }
}
```

## Limits

Up to **60** requests per minute per API key. Max range **7 days** per `from`/`to` request.
