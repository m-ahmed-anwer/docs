## Request

```
GET https://api.fleeticc.com/api/partner/v1/history
```

Identify the vehicle with **either** `vehicleId` or `imei` (must belong to the key’s owner).

### Mode A — time range (trip playback)

| Param | Required | Description |
|-------|----------|-------------|
| `vehicleId` or `imei` | yes | Vehicle identity |
| `from` | yes | Unix seconds (inclusive) |
| `to` | yes | Unix seconds (inclusive) |

Maximum window matches Fleeticc playback limits (default **7 days**).

### Mode B — nearest point (QR scan / delayed GPS)

| Param | Required | Description |
|-------|----------|-------------|
| `vehicleId` or `imei` | yes | Vehicle identity |
| `at` | yes | Scan timestamp (Unix seconds) |
| `windowSeconds` | no | Search ±N seconds (default `300`, max `3600`) |

If GPS was offline at scan time, store `at` and **retry later** until `point` is non-null.

## Response examples

### Range

```json
{
  "vehicleId": "8f3c2a1b-…",
  "imei": "35963310……",
  "plateNumber": "ABC-1234",
  "vehicleName": "Truck 01",
  "mode": "range",
  "from": 1761190000,
  "to": 1761200000,
  "record": [
    {
      "timestamp": 1761190100,
      "latitude": 7.29,
      "longitude": 80.63,
      "speed": 12,
      "heading": 90,
      "accstatus": 1
    }
  ]
}
```

### Nearest

```json
{
  "vehicleId": "8f3c2a1b-…",
  "imei": "35963310……",
  "plateNumber": "ABC-1234",
  "vehicleName": "Truck 01",
  "mode": "nearest",
  "at": 1761200000,
  "windowSeconds": 300,
  "point": {
    "timestamp": 1761199988,
    "latitude": 7.2911,
    "longitude": 80.635,
    "speed": 0,
    "heading": 10,
    "accstatus": 0
  }
}
```

`point` may be `null` when no GPS samples exist in the window.

## Rate limit

**60 requests / minute** per `X-Api-Key`.
