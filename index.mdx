## Getting started

The **Fleeticc Partner API** gives your backend live vehicle positions, vehicle identity, and GPS history. It is separate from the Fleeticc mobile app and website (those use owner login JWTs).

## Base URL

```
https://api.fleeticc.com/api/partner/v1
```

All Partner API paths below are relative to `https://api.fleeticc.com`.

<Warning>
  Partner access is **off by default**. Fleeticc must enable External Partner API on your owner account and issue an HMAC API key. Contact [info@fleeticc.com](mailto:info@fleeticc.com) if you need access.
</Warning>
