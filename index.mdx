## Base URL

```
https://api.fleeticc.com
```

All partner endpoints start with `/api/partner/v1/…`

## Before you start

1. Ask Fleeticc to **enable** the Partner API on your account  
2. As the **account owner**, open the Fleeticc website → account menu → **Partner API**  
3. Generate your **API key** and **secret** (the secret is shown only once)  
4. Follow the [quick start](/api-reference/introduction)

<Note>
  Access is off by default. Email [info@fleeticc.com](mailto:info@fleeticc.com) to request enablement. Only the account owner can create or rotate keys — team / sub-account users cannot.
</Note>
