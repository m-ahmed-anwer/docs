# Fleeticc Partner API docs

- Site: [https://fleeticc.com/docs](https://fleeticc.com/docs)
- API: [https://api.fleeticc.com](https://api.fleeticc.com)

```bash
npx mintlify dev
```

- Authentication  
- List vehicles
